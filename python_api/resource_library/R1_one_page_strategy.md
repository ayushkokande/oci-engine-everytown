Small organizations rarely need a long strategic plan to start planning beyond the next month.
A one-page strategy is enough: a mission sentence, three to five goals in plain language, the main
programs that serve each goal, and how you will know each goal is moving.

Turn it into a 6-12 month roadmap by listing, per quarter, the two or three things that must be
true by the end of that quarter (for example "second street-outreach worker hired" or "cash-flow
projection reviewed monthly"). Give every item one owner.

Make it a habit, not a document: hold a 60-90 minute planning check-in each month or quarter,
review the roadmap, and update it. Share the goals at staff meetings and ask staff to restate them;
if people cannot say the goals back, simplify them. A basic logic model (inputs -> activities ->
outputs -> outcomes) can sit beside the one-pager once the goals are stable, and becomes the
backbone for grant narratives and evaluation later.
